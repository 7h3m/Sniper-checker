📌・PRESENTATION

SNIPER CHECKER est un outil Python permettant de vérifier la disponibilité de noms d'utilisateur Discord.

Il dispose de plusieurs modes de génération, d'un système de statistiques en temps réel, de la prise en charge des proxies et de notifications via webhook.

✨・FEATURES

- 🔎 Vérification de disponibilité des usernames Discord
- ⚡ Plusieurs modes de génération
- 🚀 Système multi-processus
- 📊 Statistiques en temps réel
- 🌐 Support des proxies
- 🔔 Notifications webhook
- 💾 Sauvegarde automatique des paramètres
- 📁 Enregistrement des usernames disponibles

🧩・GENERATOR MODES

Plusieurs modes sont disponibles :

- "4c_smart"
- "3C"
- "Semi 3C"
- "Semi 2C"
- "4L"
- "4N"
- "5N"
- "Semi 4N"
- "Semi 3N"
- "Word Separators"
- "Word Pairs"
- "Dictionary"

🛠️・INSTALLATION

1. Installer Python

Télécharge Python depuis le site officiel :

https://www.python.org/downloads/

2. Installer les dépendances

py -m pip install curl_cffi requests tls_client

3. Lancer le tool

py ScanXr_Caennais.py

«Note : Renomme le fichier téléchargé en "ScanXr_Caennais.py" si nécessaire.»

⚙️・CONFIGURATION

Le menu principal permet de configurer :

Option| Description
"1"| Start Checker
"2"| Select Mode
"3"| Connection Settings
"4"| Select Speed
"5"| Webhook Settings
"6"| Save Settings
"7"| Show Taken Usernames
"8"| Auto-Claim Configuration

🚀・SPEED

La vitesse cible est configurable entre :

- Minimum : 500 CPS
- Maximum : 5000 CPS
- Default : 500 CPS

Les performances réelles dépendent notamment de la connexion et des réponses du service.

📂・FILES

Fichier| Utilité
"available.txt"| Usernames disponibles
"proxies.txt"| Liste des proxies
"settings.json"| Paramètres sauvegardés

🔔・WEBHOOK

Le système de webhook permet de recevoir des notifications concernant les résultats du checker.
