📌・ABOUT

SNIPER CHECKER is a Python-based Discord username availability checker.

✨・FEATURES

- 🔎 Username availability checking
- ⚡ Multiple generation modes
- 🚀 Multi-process system
- 📊 Real-time statistics
- 🌐 Proxy support
- 🔔 Discord webhook notifications
- 💾 Automatic settings saving
- 📁 Available usernames export

🧩・GENERATOR MODES

- "4c_smart"
- "3C"
- "Semi 3C"
- "Semi 2C"
- "4L"
- "4N"
- "5N"
- "Semi 4N"
- "Semi 3N"
- "Word Separators"
- "Word Pairs"
- "Dictionary"

🛠️・INSTALLATION

1. Install Python

""Download Python" (https://www.python.org/downloads/)

2. Install dependencies

py -m pip install curl_cffi requests tls_client

3. Launch

py main.py

⚙️・MENU

Option| Description
"1"| Start Checker
"2"| Select Mode
"3"| Connection Settings
"4"| Select Speed
"5"| Webhook Settings
"6"| Save Settings
"7"| Show Taken Usernames
"8"| Auto-Claim Configuration

🚀・PERFORMANCE

Setting| Value
Minimum CPS| 500
Maximum CPS| 5000
Default CPS| 500

Actual performance depends on network conditions and service responses.

📂・PROJECT FILES

File| Description
"available.txt"| Available usernames
"proxies.txt"| Proxy list
"settings.json"| Saved configuration

🔔・WEBHOOK

Webhook notifications allow you to receive checker result updates through Discord.

🔐・SECURITY

- Never share your Discord token.
- Keep your API keys private.
- Never publish your "settings.json".
- Respect Discord's Terms of Service.
- Avoid automated actions that could compromise your account.
